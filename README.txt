ATTANDACE PRO V5
Premium storage-light attendance PWA.

Features:
- Premium responsive dashboard
- Subject-specific minimums
- Present/absent daily marking
- Explicit HOLIDAYS page (full/half day), excluded from attendance
- Weekly timetable
- Smart planner: can I miss, recovery, safe absence margin
- History
- Analytics
- Dark/light theme
- Backup/restore
- Sample data
- Notification permission helper
- Offline cache
- Developer credit: Developed By: Tanmay Pise

Run locally:
py -m http.server 8000
Then open http://localhost:8000

Important:
This package is a PWA, not a signed Android APK. It is intentionally storage-light.
A signed APK requires a cloud Android build or Android build toolchain; no claim of a prebuilt APK is made here.
